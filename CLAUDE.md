# omocop-m365 — working notes for Claude

Opinionated Microsoft 365 MCP server over stdio. The opinion (the server signs in as a dedicated agent account, never the user) is load-bearing and documented in `docs/rationale.md`. Read it before widening any capability.

## Commands

- `npm run verify` — lint + typecheck + tests + stdio smoke test. The bar for every change.
- `npm run typecheck` uses `tsconfig.typecheck.json` (includes `test/`); `npm run build` stays plain `tsc` emitting only `src/`.
- `npm run auth` — local OAuth sign-in server; the only thing that reads `.env`.
- `npm run inspect` — MCP inspector against the built server.

## Invariants — violating any of these is a bug

- stdout is the MCP transport. No `console.*` outside `src/logging.ts` and its test (eslint-enforced); `installStdoutGuard()` catches dependencies; `scripts/smoke.mjs` proves it against a real process.
- `defineTool` is the whole design. Tools declare name, description, scopes, zod input/output shapes, optional policies, a handler, a renderer. The harness does auth, scope gating, policy execution, error translation, result wrapping. A handler growing preamble means the harness is missing a feature.
- Handlers return data; `render` derives the prose from the zod-parsed data. Never hand-build both.
- A tool whose scopes were not granted refuses without touching Graph.
- Repeated per-handler checks become policies (see `requireEventTarget`, `requireFolder`). The same check inline in a third handler means a policy is overdue.
- `domain/` stays pure. No imports from `graph/`, `server/`, `tools/`; no I/O. That is what makes its decisions table-testable.
- Never swallow a Graph error. Anything a query had to give up is reported in prose (`domain/mail-query.ts` `notes`); ambiguity refuses and explains rather than guessing.
- Graph `/messages` combination rules are encoded in `domain/mail-query.ts` and enforced by the test fake (`test/support/fake-graph.ts`): `$search` combines with neither `$orderby` nor `$filter`; every `$orderby` property must lead the `$filter`. Do not weaken the fake to make a test pass.
- Non-idempotent methods never retry on 503/504 (a late 504 can follow a completed send, and mail must never double-send). 429 retries for everything.

## Traps

- The MCP server does not read `.env`. It is launched by its client, and credentials live in the client config's `env` block; `.env` feeds `npm run auth` only. This is the most common setup failure, keep the docs saying it.
- `skills/` contains templates; installed copies are generated by `skills/install-skills.*` from a gitignored `skills.config.local.json`. Edit the template and re-run the installer with `-Force`, never the installed copy.
- V8 `Date` ISO parsing rejects out-of-range months/hours with NaN but silently rolls an out-of-range day over (Feb 30 → Mar 2); a NaN check does not validate a date. `domain/datetime.ts` round-trips instead.
- `M365_TIMEZONE` is a Windows timezone name, not IANA.
